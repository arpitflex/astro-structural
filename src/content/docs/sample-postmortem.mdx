## remediation

Capping per-route queue depth and failing fast when the shared request budget expires prevents retry amplification:

```ts
export function shouldAdmit(inFlight: number, maxInFlight: number, remainingMs: number): boolean {
  return remainingMs > 50 && inFlight < maxInFlight;
}
```

## follow-ups

- Enforce a single end-to-end deadline header across caller and worker hops.
- Alert on queue wait time in addition to error rate so backpressure surfaces early.
